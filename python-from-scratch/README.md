## 🚀 How to use this repository

### Option A — Clone with Git
```bash
git clone https://github.com/YOUR_USERNAME/python-from-scratch.git
cd python-from-scratch
```

### Option B — Download ZIP
1. Click the green **Code** button → **Download ZIP**
2. Unzip the folder
3. Open any `.py` file in Thonny

### Opening in Thonny
1. Open **Thonny**
2. `File → Open` → navigate to the `exercises/` folder
3. Open the file you want to study
4. Press **▶ Run** (F5) to execute it
